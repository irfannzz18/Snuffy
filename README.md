# Snuffy

A music player for Android. Search YouTube, play songs, make albums, and save your liked tracks.

## Features

- Search YouTube and play audio only
- Now playing screen with a spinning black disc
- Play, pause, next, previous, shuffle and repeat
- Queue
- Liked songs list with Play all and Shuffle
- Albums: create one and add songs from the **+ Add to album** button
- Play songs from `songs.txt` or `song.txt` (looked up on YouTube by name)

## Built with

- HTML, CSS and JavaScript for the interface (`app/src/main/assets/index.html`)
- Android WebView to show the interface
- ExoPlayer (Media3) for playback
- Chaquopy to run Python inside the app
- yt-dlp to find and resolve YouTube audio
- GitHub Actions to build the APK
